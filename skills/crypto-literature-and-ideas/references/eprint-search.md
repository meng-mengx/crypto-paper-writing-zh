# IACR ePrint 检索与全文获取

使用 IACR ePrint 查找密码学预印本和修订稿。使用可用的搜索、浏览或 HTTP 工具即可，无须增加服务依赖。

## 检索入口

- 官方搜索入口：`https://eprint.iacr.org/search`，查询参数 `q`；构造 URL 时对查询字符串编码，例如 `https://eprint.iacr.org/search?q=puncturable`。
- 支持短语、`title:`、`author:` 和 `AND`/`OR`/`NOT`；当前语法以搜索页 Help 为准。先用对象、机制与安全模型分别检索，按结果收窄。站内搜索覆盖标题、作者、摘要和关键词，不搜索 PDF 正文，不把结果当作全文命中。
- 取回结果后识别实际论文 ID、标题、作者、结果范围和分页；不要把空的搜索表单、拦截页或与查询无关的结果记为成功。只处理本轮相关条目，需要扩大范围再继续分页。
- 站内不可访问时，以 `site:eprint.iacr.org` 加关键词使用网页搜索定位候选，再打开官方条目核验。明确记录这是网页搜索后备，搜索引擎片段不能支持技术结论。

## 条目、版本与正文

从搜索结果进入 `https://eprint.iacr.org/YYYY/NNN`，核对作者、标题、History、Publication info 和修订/错误说明。记录 ePrint ID、实际版本日期及其与正式发表版本的关系；使用条目中的 PDF、版本历史和 BibTeX 链接，不猜造 DOI 或版本 URL。

获取 PDF 后检查内容确为 PDF、标题和版本相符，并确认相关正文可读；HTTP 200、`.pdf` 后缀或摘要页均不足以证明取得全文。使用当前可用的 PDF 工具读取，公式或页面提取有歧义时核对渲染页面。

直接 PDF 被拒绝时，优先检查同一官方条目提供的下载链接，再查 IACR 官方会议档案、作者公开稿或合法本地附件。替代版本须单独标明，修订说明涉及的证明不能用早期版本默认覆盖；可读网页工具取得的全文与已下载本地附件分别记录。连续失败后记录具体缺口，推进其他可核验关系，不把获取失败解释为论文不存在。

## 引用与记录

分析实际取得的全文；用官方 BibTeX 或核实 DOI 整理引用，记录版本、来源链接和实际阅读范围。

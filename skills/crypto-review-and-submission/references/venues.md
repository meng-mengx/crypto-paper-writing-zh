# 刊会与版本

## 会议、期刊与版本

先按[研究内容](../../../references/academic-methods.md#按研究内容选择展开重点)决定证据与组织，再适配读者和官方要求。刊会名称不决定理论、应用或实证类型，也不决定证明方法和实验比例。

相关任务中核对指南版本、篇幅口径、匿名要求，以及正文、附录和补充材料的评审范围；目标未定时继续研究内容，不猜页数删证明。比较不同版本须追踪定义、定理、引理、证明和修正状态，不能由会议短版的概述断言完整版本缺少证明。会议正文可因篇幅压缩完整论证或指向可定位的附录、技术报告或完整版本，但正文应保留理解和评价主要主张所需的研究对象或模型、关键条件、主要结果、定量界或相称证据、论证思路及完整论证的位置。补齐证明和附录的 full version 不自动构成期刊扩展；真正的扩展稿应按目标刊会要求说明实质新增或改变的贡献，增加背景、重复文字或篇幅本身不算实质扩展。关键条件和限制不能仅藏在不进入评审范围的材料中。转投或调整版本时复查主张、编号、引用和附录依赖，普通润色无需重做投稿核查。

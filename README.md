## 学术目标

从最接近的工作及其局限提出问题，说明构造的必要性，用证明、合法反例和合适实验检验主张。写作围绕问题与论证，不把工程细节或工作记录堆成论文。不同安全模型与测量口径必须说明，不能靠删去条件制造优势。
